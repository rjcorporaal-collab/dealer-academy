# Repair Care Dealer Academy

Online training voor personeel van Repair Care dealers. Twee edities, elk acht modules van
vier tot zes minuten met video en checkvragen.

- Nederlands: `index.html`
- UK English: `uk/index.html`

Beide zijn zelfstandige HTML-bestanden zonder server-onderdelen of build-stap. De enige externe
bronnen zijn Google Fonts en de YouTube-embeds.

## Deze map is gegenereerd

De bron staat in het projectarchief van Repair Care, niet hier. Pas de moduledata daar aan en
genereer deze map opnieuw; wijzigingen die je hier maakt gaan bij de volgende build verloren.

## Live zetten met GitHub Pages

Repository-instellingen → Pages → Source: *Deploy from a branch* → branch `main`, map `/ (root)`.
De site staat daarna op `https://<gebruikersnaam>.github.io/<repositorynaam>/`.

`.nojekyll` schakelt de Jekyll-verwerking uit, `robots.txt` en een `noindex` in de pagina's
houden de training uit zoekmachines.
